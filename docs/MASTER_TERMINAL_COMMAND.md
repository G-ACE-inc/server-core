# Masterへ渡すコマンドの作成方法

通常はAI自身が `host.command` を用いる。実際の接続経路を利用できない場合に限り、Masterへ貼り付け実行可能な完成コマンドを渡す。この規則はMasterに渡すコマンドだけに適用する。

- AIが対象Project・実行先・作業ディレクトリ・Shell・引数を確定する。Masterに修正・選択・技術判断を求めない。
- できる限り一つのコードブロックに一回の貼り付けで済むコマンドを完成させる。複雑な処理を無理に一行化しない。
- 提示する**最終本文そのもの**を、対象Shellの構文検査で確認する。検査後に変更したら再検査する。検査できない複雑なコマンドは提示しない。
- 作業ディレクトリを明示し、失敗してもMasterの対話Shellを終了させない。対象外の削除・再起動・上書き、秘密情報の表示を含めない。
- 実行結果が分かるように、必要な成功・失敗情報を出力する。大量のログは欠落を隠さず、必要に応じてファイルで扱う。
- Masterから実行結果が返ったらAIが判断し、修正と開発を続ける。追加の確認・承認手順を新設しない。
